# PI-Insight AI — Module Guide

1. **Dashboard:** operations overview: asset count, average health, high-risk assets and AI signals.
2. **Asset Framework:** AF-style Elements and Attributes for industrial assets.
3. **PI Trends:** PI Vision-inspired trend exploration using synthetic tag history.
4. **Event Intelligence:** Event Frames-style operational events with severity/status.
5. **AI Anomalies:** Isolation Forest detects unusual multivariate time-series behavior.
6. **REST API:** `/api/overview`, `/api/tags`, `/api/series/GEN-01.Power`, `/api/anomalies`.

Data model: `assets -> tags -> readings`; events are operational records.
